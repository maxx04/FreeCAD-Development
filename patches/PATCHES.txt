# FCProject: Liste der Patches, die update-and-rebuild-freecad.sh automatisch anwendet.
#
# Dies ist die EINZIGE Stelle, die geaendert werden muss, um einen Patch zu
# aktivieren/deaktivieren - update-and-rebuild-freecad.sh liest ENV_PATCHES/FEATURE_PATCHES
# direkt aus den beiden Abschnitten unten ([ENV] / [FEATURE]). Welche Dateien jeder Patch
# beruehrt (fuer den Reset in Schritt 1) wird automatisch aus dem Patch selbst ermittelt
# ("diff --git a/<Datei> b/..."-Zeilen), nicht mehr von Hand in einer zweiten Liste gepflegt -
# das war wiederholt Ursache vergessener Eintraege (Vorfall 2026-08-18/2026-08-23, siehe
# README.md).
#
# Format: eine Datei pro Zeile, Dateiname-PRAEFIX ist das Datum der letzten inhaltlichen
# Aenderung des Patches (YYYY.MM.DD) - KEINE Anwendungsreihenfolge. Die tatsaechliche
# Reihenfolge beim Anwenden ist: erst alle [ENV]-Patches (Zeile fuer Zeile von oben nach
# unten), danach - nur bei gruenem Vanilla-Build - alle [FEATURE]-Patches, ebenso von oben
# nach unten. Leerzeilen und "#"-Kommentare werden ignoriert.
#
# Details zu jedem einzelnen Patch: siehe README.md.
